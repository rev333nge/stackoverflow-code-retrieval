# Desktop app local inference (replaces Ollama): loads a .gguf file the user
# picks, straight into this process. The plain `pip install llama-cpp-python`
# below gives a CPU-only build -- for GPU offload on an NVIDIA card, install
# with a CUDA-enabled wheel instead, e.g.:
#   pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
# (pick the cuXXX matching your installed CUDA version; see
# https://github.com/abetlen/llama-cpp-python#installation-configuration)
#
# On a 12th/13th/14th-gen Intel CPU (P+E core hybrid), that prebuilt wheel can
# crash every generation with WinError 0xC000001D (illegal instruction): it's
# compiled assuming AVX-512, which Intel fuses off on these chips even though
# CPUID still reports it. Fix is a from-source build with AVX-512 explicitly
# disabled (needs Visual Studio + CMake installed, no separate CUDA Toolkit
# needed beyond what's already on the system):
#   $env:CMAKE_ARGS = "-DGGML_CUDA=on -DGGML_NATIVE=off -DGGML_AVX512=off -DCMAKE_CUDA_ARCHITECTURES=native"
#   pip install llama-cpp-python --force-reinstall --no-cache-dir --upgrade
llama-cpp-python
